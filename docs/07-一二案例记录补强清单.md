## 四、三条跨案例的记录教训（来自这次审计本身）

1. **"没做"也要记录。** ② 的环 3 会审被跳过，且没写一句"跳过"——结果审计时无法判断是"没做"还是"做了没记"。③ 的做法（专门写"裁剪记录 + 代价"）应成为模板。
2. **入口文档不是装饰。** ① 有三份 300+ 行的深度文档，却没有 README——评审/学员打开目录不知道从哪读。
3. **证据无索引 = 证据不可用。** 42 份 JSON 摆在那里，但"这个数字来自哪个文件"要靠翻目录，等于没有证据链。
