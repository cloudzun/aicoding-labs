## 三、口径纪律（三项目统一，已在各自 evidence/README 与 qa-report 中重复声明）

1. 同一指标不同轮次**必须带轮次标签**（如"v1.2 语义精确率 100%"）。
2. 换过分母的指标**旧口径只作对照**，不作验收、不作对外表述。
3. `not_detected` / `INCOMPLETE` / `SKIP` 均**不等于合规或通过**。
4. 合成数据的一切结论必须带"合成语料"限定词。
5. 新增门禁不得追溯历史结论（如 ③ 的语义精确率门禁 v1.2 才引入，v1.1 的 PASS 不含它）。
