## 2. 合成数据

- 30 份 `.docx`，3 类 × 10 份：采购合同 / 服务合同 / 框架协议。
- **6 份正常**（对照，全部 27 单元应判"无风险"）、**24 份各植入 3–6 处缺陷**。
- 12 类缺陷码（D01–D13，其中 D13 对应语义型"显失对等"），缺陷池扩展后**27 条规则每条至少被违反 1 次**（否则该规则无区分度——这条是首轮断言拦下来的）。
- 断言：合同 30、单元 810、正常合同零风险、植入违规数 = 真值风险数（111 = 111）。

## 4. 指标口径

```
单元级：TP = 真值 risk 且系统判 risk；FP = 系统判 risk 但真值为正常；FN = 真值 risk 但未报
```

| 指标 | 门槛 | 说明 |
|---|---|---|
| 存在型 P / R / F1 | ≥85% / ≥88% / ≥85% | 客户原话"核心风险召回≥88%"落在这里 |
| 缺失型 Recall | ≥85% | 必有条款缺失是最重要的"必查项" |
| 缺失型误报率 | ≤15% | 缺失型极易"见谁都像缺"，必须成对看 |
| 语义型 Recall | ≥70% | 主观判定，门槛单列较低 |
| 等级一致率 | ≥80% | 仅在 TP 上比较 predicted level 与真值 level |
| **定位准确率**（可定位项） | ≥90% | 数值型/结构性/语义型 TP 中，带**真实（非推断）** locator 的比例 |
| **缺失项位置覆盖率** | ≥80% | 缺失型/存在型缺失 TP 中，能给出"应出现位置（推断）"的比例；**位置为推断，精度未评估** |
| 旧口径定位率（对照） | — | 全部 TP 中"有任意定位依据"的比例，仅用于历史对比，**不作验收** |
| 报告结构通过率 | 100% | schema 完整 + 定位可回查 + 引用在定位段内 |
| 单份耗时 | p95 ≤10s | 客户原话"10 页 ≤10s" |

## 5. 三套评测

| 套件 | 规模 | 判定 |
|---|---|---|
| 规则命中集 | 810 单元 | 自动比对（TP/FP/FN） |
| 报告质量集 | 30 份 | 结构 + 定位回查 + 引用一致性 |
| 锚点集 | **20 条** | 真值 + 原文核验（**非客户独立标注**，如实标注） |

**尺子自检（BP-2）：**
- 报告质量检查器本身有 4 条规则（字段齐、等级合法、定位段存在、引用在段内）——它先于评测跑；
- 语义判定要求"证据必须能在原文定位"，否则降级 `not_detected`（防止 LLM 幻觉当结论）。

## 6. 本轮踩到并修掉的三个数据/检测缺陷

| 缺陷 | 现象 | 修法 |
|---|---|---|
| 关键词满篇匹配 | "期限"命中"保密期限"、"付款"命中"收到发票后付款" → 缺失型 recall 仅 **25%** | 改为**条款标题匹配**（先"第X条"，再标题词） |
| 缺陷互斥冲突 | 语义缺陷条款自带"违约责任"标题，却同时声明该条款缺失 → 真值自相矛盾，recall 被压到 50% | 生成器冲突消解：D06/D07/D08 与 缺R11/R05/R12 互斥 |
| 数值抽取只取 group(1) | R15 的备选分支写在 group(2) → 永远 not_detected | 取第一个非空分组 |

**教训（与 ② 同源）：题库内部一致性也要断言。** 这三条都是"断言/评测"先暴露、代码后修。

## 7. 边界

- 合成合同覆盖 3 类 × 12 类缺陷，**不代表真实合同的全部风险形态**。
- 分级（高/中/低）来自规则的 `severity` 固定映射，未做"偏离度升级"。
- `not_detected` 在报告中显式列出，**不等于合规**。

## 8. 指标口径变更记录（2026-10-20，诊断驱动）

**诊断证据（`evidence/diag-*.json`）：**

| 发现 | 数据 | 结论 |
|---|---|---|
| 缺失型 7 条 FN 全是 R11 | 7/7 由"整段含标题词即命中"导致（如『第二十条 对等责任 / 双方违约责任对等…』） | 匹配必须限定标题范围 |
| 可定位项定位率 | 数值 26/26、结构 4/4、语义（子集）13/13 全部有真实 locator | 旧"定位率 47.62%"是分母含无位置项所致，**非工程缺口** |
| 语义降级 | 子集 6 份中降级 0 条 | 语义定位链路在合成语料上健康；真实长文待验 |

**变更：**
1. `detect_present` 只匹配标题部分（新增 `heading_part`），并支持 `heading_aliases`（真实合同写法差异，合成语料未引入偏差）。
2. 新增"缺失项位置推断"：缺失条款给出参照位置并标 `inferred=true`（**不是精确位置**）。
3. 指标拆分：定位准确率 + 缺失项位置覆盖率；旧口径保留作对照，**禁止用旧口径宣称提升**。

**结果（确定性全量 30 份）：** 缺失型 Recall 76.67% → **100%**；定位准确率 **100%**；缺失项位置覆盖率 **100%**；缺失型误报率仍 **0%**；总体 P/R/F1 = **100/100/100**。
