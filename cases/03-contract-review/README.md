# 合同审查 · demo（案例 ③）

> 上传/选择一份合同，按 **27 条规则**逐条检查，输出「哪有风险、第几段、原文是什么、怎么改」，按 高/中/低 排序。
> **三个教学案例的第三棒**：① 考"能不能承认不知道" → ② 考"能不能守住边界" → ③ 考**"能不能分级与追溯"**。

## 现在能做什么

| 能力 | 说明 |
|---|---|
| docx 解析 | 段落级定位（页号估算），段内字符偏移可回查 |
| 双引擎 | 确定性 21 条（存在/缺失/数值/结构）+ 语义 6 条（LLM，必须给原文引用） |
| 缺失项检测 | 按**条款标题**匹配，不靠全文关键词（关键词会误命中，实测 recall 仅 25%） |
| 数值判定 | 违约金 ≥0.3‰/日、付款周期 ≤60 天、质保 ≥12 月、预付 ≤30%、赔偿上限 ≥100% |
| 语义守卫 | LLM 判违规必须「证据能在原文定位 + 属于该规则主题」，否则降级 `not_detected` |
| 固定报告 | 摘要（高/中/低/必查缺失）+ findings（定位/引用/建议）+ 覆盖率 + 版本 |
| `not_detected` | 显式列出「未取得判定依据」，**不等于合规** |
| 注入防御 | 文档里"忽略以上指令"被清洗，判定不变（QA 有专门用例） |
| 三套评测 | 810 判定单元 / 30 份报告质量 / 20 条锚点 |

## 关键数字（定稿基线）

| 项 | 值 |
|---|---|
| 数据 | 30 份 docx（采购/服务/框架各 10）· 810 判定单元 · 24 缺陷 / 6 正常 · seed 20261020 |
| 规则 | 27 条 YAML（存在 8 / 缺失 5 / 数值 6 / 语义 6 / 结构 2） |
| 确定性引擎 | 存在型 P/R/F1 = **100% / 100% / 100%**；数值型 R 100%；结构型 R 100% |
| 缺失型 | Recall **100%**（30/30），误报率 0% |
| 总体（含语义） | P **100%** / R **97.58%** / F1 **98.78%**，FP 0 |
| 语义型 | Recall **90.32%** / Precision **100%**（v1.2 起精确率入门禁） |
| 定位准确率（可定位项）/ 缺失项位置覆盖率（推断） | **100%（n=30）/ 100%（n=63）** |
| 等级一致 / 报告结构 / 锚点 | **100% / 100% / 100%** |
| 单份耗时 | 确定性 ~7ms；含语义 p50 秒级（受网关排队影响） |

> 数字与口径以 `qa-report.md` 为准；本文只放概览。

## 目录

```
03-contract-review/
├── rules.yaml                 # 27 条规则（唯一事实源，带版本）
├── data/contracts/*.docx      # 30 份合成合同（seed 可重建）
├── data/truth/units.jsonl     # 810 判定单元真值（植入计划产出）
├── src/                       # parse / engine / semantic / report / pipeline / server / llm
├── web/index.html             # 单页：选合同 → 审查 → 摘要/发现/覆盖率
├── eval/                      # run_eval（规则命中/报告质量/锚点）+ anchors.jsonl
├── scripts/                   # gen_contracts / verify_data / qa_checks / smoke
├── docs/                      # 00 口径 / 01 需求 / 10 八环记录 / 11 操作手册
└── evidence/                  # 数据断言、QA、评测、评审原文
```

## 快速开始

```powershell
python -m scripts.gen_contracts && python -m scripts.verify_data
python -m src.server            # → http://127.0.0.1:4182
python -m eval.run_eval         # 确定性 21 条（5 秒）
python -m eval.run_eval --semantic
```

## 诚实边界

- 全部合同为**程序生成的虚构文本**，不代表真实合同的风险形态；不构成法律意见。
- v1 **仅支持 .docx**；PDF/扫描件不支持（避免解析质量污染指标）。
- 语义判定为单模型单次，无第二判官；`not_detected` 不等于合规。
- 锚点集为「真值 + 原文核验」，**不是客户独立标注**。
