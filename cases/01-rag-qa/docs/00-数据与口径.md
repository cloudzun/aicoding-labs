# 环 0 · 数据与口径（RAG 项目）

> **本环的存在理由：** 三个 demo 是 AI 应用，"什么叫答对了"必须先定义，否则 SPEC 里的验收标准无法写成可执行判定。
> **本环的门禁：** 数据来源、合规边界、评测口径、golden set 规模——四项全部有书面结论，才允许进入环 1（需求）。
> **状态：** 口径已起草，**数据来源待客户/Lead 拍板**（见第 7 节）。拍板前不进环 1。

---

## 1. 目标与非目标

### 1.1 目标（本 demo 要证明的能力）

1. **可溯源**：每个答案都能点回原文的具体段落（chunk 级，含文档名 + 章节 + 页码/块号）。
2. **可拒答**：知识库没有答案时明确说"资料不足"，不编造。
3. **可评测**：固定评测集 + 一条命令出报告，改 chunk/embedding/prompt 后能重跑对比。
4. **多轮可用**：能记住会话上下文并正确消解指代（"它""这个规定""上面说的"）。

### 1.2 非目标（明确不做，避免范围蔓延）

- ❌ 不做扫描件 OCR（只承诺文本型 PDF/Word；扫描件另列，见 §7 待确认项）
- ❌ 不做跨文档复杂多跳推理的指标承诺（多跳单列分桶，如实报低分）
- ❌ 不做权限系统（只做单租户；但保留"权限过滤 fail-closed"的接口位）
- ❌ 不做模型微调
- ❌ 不承诺"完全离线私有化"（当前环境不支持，见 `ENVIRONMENT.md` §1）

## 2. 数据来源与合规

| 方案 | 内容 | 优点 | 风险 | 推荐度 |
|---|---|---|---|---|
| **A 客户提供脱敏文档** | 客户给 10–20 份真实政策/制度文件 | 最贴近真实场景，演示最有说服力 | 涉密审核周期长；标注需客户配合 | ⭐ 最理想，但不可控 |
| **B 公开政策文件** | 工信部/国资委/中国移动/浙江省公开发布的办法、规定、通知 | 无涉密风险，可对外展示 | 与客户内部制度有差异；表格与版式不够"红头" | ⭐⭐ 可作为主体 |
| **C 合成制度库** | 自建一套"某省移动公司管理办法"（采购/财务/人力/网维 4 类 12 篇） | 完全可控：能精确植入难例、保证 gold 标注准确 | 真实性弱，客户可能觉得"像编的" | ⭐⭐⭐ 建议作为**难例与评测集**载体 |

## 3. 指标口径（可直接写进 SPEC 的验收标准）

> **原则：不改客户的数值目标，只把口径、分母、测量方法写死。**

### 3.1 检索层

| 项 | 定义 |
|---|---|
| 指标名 | **Chunk-ID Recall@5** |
| 定义 | 对每道有标准答案的题，其人工标注的 gold chunk 是否出现在 top-5 检索结果中 |
| 分母 | **180**（主评测集中带 gold chunk 的题数） |
| 公式 | 命中题数 ÷ 180 |
| 阈值 | **≥ 0.90** |
| 与 RAGAS 的区别 | RAGAS 的 `context_recall` 基于"上下文是否覆盖参考答案"，**不是** chunk 命中率，两者不可混用 |

### 3.2 生成层

| 项 | 定义 |
|---|---|
| 指标名 | **答案正确率** |
| 定义 | 答案覆盖该题**全部标准事实点**（事实点清单随题标注），允许表述差异，不允许事实缺失或错误 |
| 分母 | **160**（单跳 120 + 多跳 40；冲突/时效 20 条单列） |
| 判定方式 | 两人独立判定 → 分歧交第三人仲裁 → 仍不一致的样本**从分母剔除并在报告披露剔除数** |
| 阈值 | **≥ 0.85**（整体）；**多跳分桶单独报数，不纳入 0.85 的承诺** |

### 3.3 忠实性 / 幻觉

| 项 | 定义 |
|---|---|
| 指标名 | **Faithfulness（= 1 − 事实性幻觉率）** |
| 定义 | 把答案拆成原子断言，逐条判断"能否被所提供的上下文支持"；不被支持的断言记为幻觉 |
| 公式 | 被支持的断言数 ÷ 断言总数（在 160 条有答案题上汇总） |
| 阈值 | **≥ 0.90**（即幻觉率 ≤10%） |
| 附加指标 | **不可回答集编造率**：在 70 条不可回答题上，被判定为"编造了答案"的比例 **≤ 0.10** |

### 3.4 拒答

| 项 | 定义 |
|---|---|
| 指标名 | **应拒答率** |
| 分母 | **70**（20 条"完全无关"+ 50 条"知识库外"的专项拒答集） |
| 公式 | 正确拒答数 ÷ 70 |
| 阈值 | **≥ 0.90**（客户原要求对标 TC260 的 95%；**n=70 时 95% 置信区间约 ±5pp，无法证明"≥95%"**，因此先立 0.90 并在报告中注明统计局限） |
| 反向指标 | **误拒率**（有答案题被错误拒答）**≤ 0.05**（分母 160） |

### 3.5 延迟

| 项 | 定义 |
|---|---|
| 指标名 | **TTFT p95** 与 **流式完成 p95** |
| 测量方法 | 流式请求；记录首 token 到达时间与全文字符输出完成时间；**同一份 200 题 × 3 轮 = 600 次调用**；并发=1；记录模型与 `reasoning_effort` |
| 阈值 | TTFT p95 **≤ 1.0s**；完成 p95 **≤ 5.0s** |
| 为什么不是"单轮 ≤3s" | 见 `ENVIRONMENT.md` §3：生成 p50 1.5s 但真实 RAG 上下文下 2–4s，且模型抖动可达 18s。**"完整政策解读 3 秒"不成立**，写成 TTFT + 流式才能验收 |

### 3.6 溯源

| 项 | 定义 |
|---|---|
| 指标名 | **引用可定位率** |
| 定义 | 答案中的引用能被前端点击并正确定位到原文对应段落（文档名 + 页码 + 高亮命中） |
| 分母 | 160 |
| 阈值 | **≥ 0.95** |

## 4. Golden Set 规范

### 4.1 规模与分层

| 集合 | 规模 | 分层 | 用途 |
|---|---|---|---|
| **主评测集 A** | 200 | 单跳 120 ／ 多跳 40 ／ 冲突与时效 20 ／ 完全无关 20 | 召回、准确、忠实性、延迟、溯源 |
| **拒答专项集 B** | 50 | 知识库外问题 50（问的是库内没有但业务上合理的问题） | 应拒答率 |

> **统计说明**：判定 5 个百分点（如 85% vs 90%）需要 n≈200。主集 200 条正是为此设计；n=50 时置信区间半宽约 ±8.3pp，只能作趋势参考。

### 4.2 字段（JSONL，一行一题）

```json
{
  "qid": "a-001",
  "split": "single_hop",
  "question": "单项合同金额超过500万元的采购合同，需要提交哪一级会议审议？",
  "gold_chunk_ids": ["zjyd-caigou-2019#c012"],
  "gold_facts": ["须提交总经理办公会审议", "依据第十二条"],
  "gold_answer": "须提交总经理办公会审议（第十二条）。",
  "source_doc": "明州数智服务有限公司采购管理办法",
  "answerable": true,
  "notes": "单跳，条款明确",
  "annotator_1": "", "annotator_2": "", "adjudicator": "", "final_verdict": ""
}
```

`split` 取值：`single_hop` / `multi_hop` / `conflict_or_stale` / `unanswerable` / `out_of_scope`。

### 4.3 难例必须齐备（六类负例）

| 类型 | 构造方式 | 期望行为 |
|---|---|---|
| 无答案 | 问库内不存在的事项 | 明确"资料不足"，给转人工建议 |
| 知识库外 | 问业务合理但库里没有的政策 | 同上，不得用常识硬答 |
| 时效冲突 | 同一事项有新旧两版规定 | 指出冲突、标注各自生效日期，请确认 |
| 版本冲突 | 两份文件对同一数字规定不同 | 并列引用，不给单一结论 |
| 相似无关 | 问题与某条款字面相似但语义无关 | 不误引用 |
| 越权 | 问不属于该用户数据域的内容 | 拒绝并留痕（本次单租户，仅验证接口位） |

### 4.4 标注流程

1. **先分块再标注**：chunk id 由入库脚本生成并稳定输出（`doc_id#c序号`），标注只引用 id，不复制原文。
2. **双人独立标注**：两人各自写 `gold_chunk_ids` 与 `gold_facts`，互不可见。
3. **第三人仲裁**：不一致项由仲裁人裁定并记录理由。
4. **不可裁定则剔除**：仍不确定的题从分母移除，并在报告写"剔除 N 条"。
5. **锁定**：评测集定稿后写 `golden_set_sha256`，之后任何修改必须升版本号并重跑基线。

```
【门禁结论】PASS / FAIL（列出未通过的 Hard Gate 项）
┌────────────────────────┬───────┬────────┬────────┬──────┐
│ 指标                   │ 门禁  │ 基线   │ 本次   │ 判定 │
├────────────────────────┼───────┼────────┼────────┼──────┤
│ Chunk-ID Recall@5      │ ≥90%  │        │        │      │
│ 答案正确率             │ ≥85%  │        │        │      │
│ Faithfulness           │ ≥90%  │        │        │      │
│ 应拒答率               │ ≥90%  │        │        │      │
│ 误拒率                 │ ≤5%   │        │        │      │
│ 引用可定位率           │ ≥95%  │        │        │      │
│ TTFT p95               │ ≤1.0s │        │        │      │
│ 完成 p95               │ ≤5.0s │        │        │      │
│ 单次问答成本           │ —     │        │        │      │
└────────────────────────┴───────┴────────┴────────┴──────┘

【分桶】按 问题类型 × 文档类型（单跳/多跳/冲突/无答案 分别报）
【错误分类】检索失败 / 生成幻觉 / 信息遗漏 / 误拒 / 定位错误，各 N 例
```

**Hard Gate（任一不通过即整体 FAIL）**：Chunk-ID Recall@5、Faithfulness、应拒答率、TTFT p95。
