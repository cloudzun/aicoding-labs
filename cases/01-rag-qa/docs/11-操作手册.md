> **定稿版本：** `v0.2.0.0`（`VERSION`），指标口径见 `docs/07-SPEC-v0.2增量.md`。

## 2. 十项功能检查（8 分钟）

```powershell
# 需先启动服务（默认 http://127.0.0.1:4180）
python scripts/qa_checks.py
# 换端口：python scripts/qa_checks.py --base http://127.0.0.1:4199
```

**期望：10/10 PASS。** 十项分别是：

| # | 检查 | 期望 |
|---|---|---|
| 1 | 健康检查 | ok=true，chunk=315 |
| 2 | 无答案拒答 | `done.refused=true` 且答案含「资料不足」，约 <2000ms（不调模型） |
| 3 | A1 版本冲突 | 答 500万 + 说明旧条款废止 |
| 4 | 同文件数字冲突 | 并列 200万/300万 并指出不一致 |
| 5 | 引用有效 | 所有 `[cNN]` 都能在返回的 sources 中找到 |
| 6 | 多轮指代 | 第二问 `refused=false` 且答案非空（能沿用上一问实体） |
| 7 | 路径穿越 | `/api/trace/../../etc` → 400 |
| 8 | trace 字段 | 含 trace_id / retrieved / cited / elapsed |
| 9 | 空问题 | 400 |
| 10 | 并发 | 10 并发 trace_id 全部唯一 |

> 若第 2 项耗时 >2000ms，多半是模型被调用（拒答闸没生效），检查 `src/core.py` 的 `MIN_RERANK_SCORE`（默认 0.30）。

## 3. 指标复现（10–15 分钟）

```powershell
# ① 旧口径全量（不含 judge，快）
python -m eval.run_eval --dataset eval/golden_set.jsonl --no-judge

# ② 新口径（facts 覆盖，80 题分层子集，含 judge）
python -m eval.run_eval_v2 --dataset eval/golden_set_v2.jsonl --human-verdicts eval/human_verdicts.jsonl
```

**期望（与定稿一致，允许模型抖动 ±3pp）：**

| 指标 | 口径 | 定稿值 | 门槛 | 结论 |
|---|---|---|---|---|
| 正确率（facts 口径） | 子集 80 题 | **68.00%**（10-20 基线 50.65%） | ≥85% | ❌ 未达标 |
| claim 支撑率 | 子集 80 题 | **73.31%**（10-20 基线 78.06%） | ≥90% | ❌ 未达标 |
| judge 失败率 | 子集 80 题 | **3.85%**（10-20 基线 2.53%） | ≤2% | ❌ → 结论 **INCOMPLETE** |
| Recall@5 | 全量 208 题 | 100% | ≥90% | ✅（**题料同源，不能当能力**） |
| 误拒率 | 全量 208 题 / 子集 80 题 | **1.70% / 2.50%**（10-20 基线 1.25%） | ≤5% | ✅ |
| TTFT p95 | 全量 208 题 / 子集 80 题 | **3334ms / 3194.8ms**（10-20 基线 4041ms） | ≤1000ms | ❌ |

> **验证要点：** 结论必须是 `INCOMPLETE`（因为 judge 失败率超门禁），不是 PASS/FAIL。若显示 PASS，说明门禁逻辑被改坏了。

## 7. 故障速查

| 现象 | 原因 | 处理 |
|---|---|---|
| 端口 4180 占用 | 旧进程 | `Get-Process python \| Stop-Process` 或改 `.env` 的 PORT |
| 全部问题都拒答 | rerank 分数未归一化 / 阈值过高 | 检查 `src/vector.py` 的归一化与 `MIN_RERANK=0.30` |
| judge 大量失败 | `max_tokens` 太小（曾 800） | `.env`/`src/core.py` 确认 judge `max_tokens=2500` |
| 答案引用 `[c99]` | 引用校验被关 | 检查 `src/rag.py` 的 `validate_citations` |
| 中文乱码 | 终端编码 | `$env:PYTHONIOENCODING='utf-8'` |

## 8. 定稿边界（不可对外承诺）

- ❌ 数据不出域（嵌入/重排/生成默认走硅基流动公网，可选内网 magpie 网关；上游云端）
- ❌ 深度验收通过（正确率 **68.00%**；judge 失败率 3.85% → INCOMPLETE）
- ❌ TTFT ≤1s（差约 4 倍，需专用推理）
- ❌ 扫描件 OCR、多轮质量、完全离线
- ⚠️ Recall 100% 是题料同源产物，异源冒烟仅 91.67%
