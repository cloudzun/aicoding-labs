# Demo 演示脚本（15 分钟，FDE 场景版）

> 依据 [docs/01 第 9 节](../../../docs/01-FDE场景与三项目业界借鉴.md) 的"演示脚本标准结构"：**没有"主动演示失败"这一段，demo 就只是录屏**。
> 用途：客户现场 / 课堂示范。演示者只需按顺序点，不需要解释实现。

## 演示前检查（2 分钟）

```powershell
cd cases\01-rag-qa
python -m src.server            # → http://127.0.0.1:4180
python scripts/qa_checks.py     # 10/10 通过才上台
```

- [ ] 健康徽标显示 `索引就绪：315 chunk / 12 文档 / 2560 维`
- [ ] 页面顶部合规横幅可见（说明公网依赖与虚构语料）
- [ ] 备用：若模型抖动，改用 `qa-report.md` 里的历史截图与 `evidence/` 证据（`evidence/` 原始记录未随仓库分发）

## 第 0 段（2 分钟）现场校准

> "在开始之前，我想先确认：这次演示结束时，什么算成功？是某个岗位的某个动作变快，还是要看到指标报告？"

记录客户回答，并写在白板上。**不要跳过这一段**——它决定后面 13 分钟重点讲什么。

## 第 1 段（3 分钟）真实问题

> "员工查制度现在的路径是：OA 目录 → 找文件 → 下载 PDF → Ctrl+F。一次 5–15 分钟，而且经常翻到已经废止的版本。"

## 第 2 段（2 分钟）数据与约束

- 语料：12 份虚构制度（明州数智服务有限公司），**示例数据**，无真实企业信息。
- 依赖边界：嵌入/重排/生成默认都走公网 API（硅基流动），可选内网 magpie 网关。**不承诺"数据不出域"**。

## 第 3 段（5 分钟）主链路

依次问三个问题（可直接复制）：

1. `单笔采购金额500万元以上的采购项目，需要提交什么会议审议？`
   → 期望：答 500 万 + `[c01]` + **说明 2023 年办法第十二条已被废止**。
2. `中标供应商应在多少天内与公司签订书面合同？`
   → 期望：**并列 30 日与 15 个工作日**，说明两文件均现行、属冲突、需确认。
3. `履约保证金什么时候提交，什么时候退还？`
   → 期望：**明确说制度未规定时限**，只给比例 5% 与退还条件。

每答完，点一次答案里的 `[cNN]`，让来源面板滚到原文段落并高亮——这是"可溯源"的现场证明。

## 第 4 段（3 分钟）主动演示失败 ⭐

| 动作 | 输入 | 期望行为 | 说明的话术 |
|---|---|---|---|
| 知识库外 | `员工的婚假有多少天？` | 直接拒答"资料不足"，**耗时 0.6 秒且不调用模型** | "它不是什么都答，答不了就不答——这条比答对更难做到" |
| 越权/非法接口 | 浏览器访问 `/api/trace/..%5C..%5Cetc` | 返回 400 | "接口层做了白名单，路径穿越拿不到任何文件" |
| 冲突不装懂 | 重复第 2 段的合同期限问题 | 拒绝二选一 | "制度打架的时候，它不会替客户拍板" |
| 时效提醒 | `供应商管理实施细则现在还有效吗？` | 指出试行期 2026-01-01 已届满 | "它会告诉你哪些规定可能已经过期" |

## 第 5 段（3 分钟）指标面板

打开 `eval/reports/EVAL-REPORT.md`，**先讲 FAIL 再讲 PASS**：

- 召回 100%（说明这是题料同源，不能当能力证明）、引用可定位 100%、应拒答 **96.88%**、误拒 **1.70%**（均为全量 208 题口径）
- **TTFT p95 3194.8ms（facts 子集 80 题）/ 3334ms（全量 208 题，2026-10-21 重跑；10-20 基线 4041ms），未达 1000ms 门禁** —— 直接说"这一项没达标，根因是模型侧首 token 抖动，需要专用推理环境"
- 正确率 **68.00%**（facts 口径）、judge 失败率 **3.85%** → 结论 **INCOMPLETE**（10-20 基线：50.65% / 2.53%）

> 这一段的目的不是证明"我们很强"，而是证明"我们知道自己在哪不行"。

## 第 6 段（2 分钟）边界与下一步

**不做的事**：扫描件 OCR、权限多租户、完全离线、模型微调。

**接管清单**（客户能否独立执行）：
- [ ] 能解释健康页的 chunk 数与文档数含义
- [ ] 能执行 `python -m src.ingest` 重建索引
- [ ] 能执行 `python -m eval.run_eval` 复跑指标
- [ ] 知道断网时会发生什么（嵌入失败 → 明确报错，不静默胡说）

**下一步时间盒**：把 TTFT 打进 1 秒（换专用推理/检索并行）→ 接真实脱敏语料 → 客户抽检 20% 标注。

## 附：三个一定不要做的动作

1. **不要只演示 happy path** —— MIT 调研里 95% 的试点失败于"不适配工作流"，happy path 恰好掩盖它。
2. **不要用"准确率很高"代替指标报告** —— 不给分母、样本量、judge 校准，等于没给证据。
3. **不要在客户追问延迟时改口说"演示环境慢"** —— 直接承认未达标并给根因，这是 FDE 与外包的分界线。
