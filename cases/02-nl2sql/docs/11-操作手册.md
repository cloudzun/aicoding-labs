## 4. 指标复现（10–15 分钟）

```powershell
python -m eval.run_eval            # 主集 150
python -m eval.run_eval --anchors  # 锚点 20
python -m eval.run_eval --ambiguity # 歧义 15
```

**期望（定稿基线，允许模型抖动 ±3pp）：**

| 指标 | 定稿值 | 门槛 | 结论 |
|---|---|---|---|
| EX（主集） | **83.33%（125/150）** | ≥85% | ❌ |
| 可执行率 | **100%** | ≥95% | ✅ |
| 单表桶 | 90.0% | ≥90% | ✅ |
| JOIN 桶（两表+三表） | **68.0%** | ≥80% | ❌ |
| 聚合/时间/空值 | 86.7% / 100% / 93.3% | ≥80% | ✅ |
| 锚点一致率 | **100%（20/20）** | ≥85% | ✅ |
| 歧义反问率 | **80%（12/15）** | ≥60% | ✅ |

- 结论必须是 `FAIL`（EX/JOIN 未达标；单表本次 90% 恰好压线），**不是 PASS**。

## 6. 故障速查

| 现象 | 原因 | 处理 |
|---|---|---|
| `端口 4181 被占用` | 旧进程 | 改 `.env` 的 `PORT` 或结束 python 进程 |
| health `db_exists=false` | 没建库 | `python -m scripts.gen_db` |
| 所有查询超时 | 网关慢 / 首启加载 | 重试；超时值是 `src/safety.py: TIMEOUT_S_DEFAULT`（10s）常量，`.env` 的 `QUERY_TIMEOUT_S` 尚未接入 |
| 全部被拒（只读） | authorizer 白名单与表名不符 | 检查 `src/db.py: ALLOWED_TABLES` |
| 生成失败 | 网关不可达或模型名错 | 默认档：`curl.exe https://api.siliconflow.cn/v1/models -H "Authorization: Bearer <你的 key>"`；内网档 B：`curl.exe http://127.0.0.1:3425/v1/models` |
| 正常业务问句被拒为写操作 | 意图闸词表 | 检查 `src/pipeline.py: WRITE_INTENT`（`新增/添加` 已放行） |
| 问题被要求先确认口径 | 阻塞式歧义（营收/近三月） | 在问题里写清口径，如"应收（含调整）" |

## 7. 定稿边界（不可对外承诺）

- ❌ 数据完全虚构，**不可用于任何对外口径引用**
- ❌ EX 83.33%（2026-10-21 重跑）未达 85%；JOIN 桶 68% 是真实短板（模型会用 product_name 关联、漏去重）
- ❌ 延迟 p50 2019ms 超 2s（p95 2950ms），属网关排队，非代码可优化
- ❌ 复杂窗口函数（同比/环比）、多轮追问、写操作、跨库
- ⚠️ "AST 白名单"实为**静态正则 + SQLite authorizer 运行时强制**，不是语法树解析
- ⚠️ 独立评审用 `glm-5.3`（不同家族）替代 codex，**非沙箱执行**
