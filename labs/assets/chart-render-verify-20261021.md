> 原则：只读后端返回的 `chart.type / chart.x / chart.y`，前端不重新猜；纯内联 SVG、零依赖；不参与 EX 判定，不改 SQL 与行数。

## 一、实现要点

| 项 | 实现 |
|---|---|
| 卡片 | 结果卡之后新增「图表」卡（`#chartCard`），标题显示 `类型 · 理由` |
| kpi / kpi_group | 大字数值，保留原始精度（千分位），如 `541,252.34` |
| line | 折线 + 数据点，X 轴自动抽稀（最多 10 个刻度） |
| bar / bar_h | 类别 ≤12 竖向；>12 或 `bar_h` 转横向并限 15 条，右上标"仅显示前 15 / N" |
| pie | 扇形 + 右侧图例（百分比） |
| scatter | 双数值散点 |
| table / empty | 不显示图表卡（回落表格） |
| 负值 | 以 0 为基线上下绘制 |
| 截断 | `truncated=true` 时标题标"结果已截断" |
