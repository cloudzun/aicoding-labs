## 三、根因（两处同一类错误）

两个页面的 `$` 都是 CSS 选择器别名：

```js
const $ = s => document.querySelector(s);
```

但调用时传的是**裸 id**（没有 `#`），`querySelector('clarCard')` 会被当成标签名查询，返回 `null`：

案例二 `web/index.html`：

```js
94:  function show(sel, on){ $(sel).style.display = on ? 'block' : 'none'; }
100: ['clarCard','rejCard','sqlCard','resCard','metaCard'].forEach(s=>show(s,false));   // 第一个就抛
112: show('clarCard', true);  117: show('rejCard', true);  120: show('sqlCard', true);
125: show('resCard', true);   130: show('metaCard', true);
```

案例三 `web/index.html`：

```js
88: ['sumCard','findCard','metaCard'].forEach(s => $(s).style.display='none');   // 第一个就抛
```

后果链：`ask()/review()` 先置 `busy = true`、按钮 `disabled = true`，随后在重卡片时抛 `TypeError`（在 `try` 之前/之外），`finally` 不执行 → `busy` 永久为 true → 之后点击直接 `if(busy) return` → **永远没反应**。

案例一没有这个写法（直接用 `getElementById` 与 `addEventListener`），故正常。

## 四、修复方案（各 1 行，二选一）

**方案 A（推荐）** 让 `$` 兼容裸 id：

```js
// 案例二、案例三 web/index.html 各改这一行
- const $ = s => document.querySelector(s);
+ const $ = s => document.querySelector(s.startsWith('#') ? s : '#' + s);
```

理由：所有既有调用（`$('#q')`、`$('#cid')` 等）不受影响；7 处 + 1 处裸 id 调用一次性修好；改动面最小、可逐字核对。

**方案 B** 逐个调用点补 `#`（案例二 7 处、案例三 1 处）。改动行数多，易漏。
